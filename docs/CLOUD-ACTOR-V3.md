# 新造形の顔と全身演技 · 2026-10-12 JST

## Scope
ユーザーの「詰めていこう」に対し、探索と休憩に残っていた旧モコモを新造形へ移行し、12感情を試す画面も統一。ホームと共通Moco表示は既にv3画像。連続した短編とMP4 v1–v7は、別の手と星の接続を持つ旧リグのまま。新造形の動画公開済みとは扱わない。

## Identity and asset
`public/characters/moco/performance/cloud-body-v3.webp`: 1254×1254 RGBA、125312bytes。
Built-in image generationで了承済みhero-v3透過画像を編集し、元の広く低い非対称の白い雲一体形、3本ずつの頬線、細かな綿の質感、体につながる手足を維持。目・口・星のみ除き、同じ位置の小さい手を体の前に残す。全身は一枚に保ち、分離部品にしない。WebP quality96／exact変換、生成PNGとalpha完全一致。生成元は本作業の `exec-5d35b9e1-5878-4f5f-85a2-fd721b4e7600.png`。

顔の配置は元heroの瞳と口の位置を測り、SVGへの換算をもとに設定。親の全身と顔アンカーが同じ変形を受ける。目は小さいマットな色、追加の光沢点と丸い赤みを抑え、元の頬線を保つ。既存filmのCharacterFaceはsoft指定なしで従来表現を維持する。

## Acting
新CloudMocoは12感情の数値姿勢を460msで補間。途中で違う感情へ変わっても現在の姿勢から連続して移る。RAFは変化中だけ動き、完了やunmountで止まる。気づく時の視線は小さく、呼吸・覗く・分ける・喜ぶ・風への反応は全身の低い振幅の移動と拡縮で表現。体につながる手は同じ画像内に固定され、独立して外れない。

手を振る・持ち上げる専用の腕の演技や、正面から横へ本当に回る動きではない。現時点は固定した正面全身の自然な変形。短編の新しい手と星の接続には専用の新造形素材・寸法の制作が必要。

## Reduced motion and feeling preview
quietとOSの動き低減を監視し、体・瞬き・顔補間を止めて最終の表情を表示。気持ちを試す画面では「映画が停止中」という理由で顔まで瞬時に切替えないよう、映画のstillと、気持ちのquietを分ける。映画自体の停止・再開・時計は維持する。
