# MOCOMO redesign · 2026-10-12

## Decision and identity
2026-10-11、ユーザーが既存造形を抜本的に見直すよう指示。人気作品の形だけでなく、個性・物語・動き・商品展開の仕組みを分析した。2026-10-12 JST、「悪くないな、こちらで進めようか」と、非対称の雲の全身と頬の短い線を持つ制作案で進めることを了承。
今回の新基準は、左右で高さの違う広い雲の輪郭、頭と体の一体形、短くつながった手足、小さなつやを抑えた瞳、小さな微笑み、左右の頬の3本の薄いピンクの線、白い柔らかな質感。旧ブランドガイドの丸い頭と別胴体／3つの球状ちょこんは、今後制作するモコモの基準ではない。旧素材は移行中の既存作品を保つために残す。

性格案: 小さなうれしいことを見つけると、誰かと分けたくなって少し頑張りすぎる雲の子。安心できる隣の友達という世界観を維持する。固有演技案: 見つける→少し前のめりに縮む→そっと差し出す。今回の実装は全身の穏やかな揺れであり、この一連の専用演技や連続した動画マスターはまだ制作していない。

## Assets and prompts
Built-in image generationで了承済み制作ボードを参照し、透過アトラスを制作。フォーマット変換のみWebPに実施し、輪郭の再描画や自動切り抜きは行っていない。
- expressions-v2.webp: 2172×724、横3等幅セル、happy / wonder / rest。121344 bytes。
- reactions-v2.webp: 1254×1254、2×2等幅セル、laugh / listen / tickle / thanks。144126 bytes。

共通プロンプト: 了承済み新モコモの非対称2段雲輪郭、白い頭体一体形、小さいマットな瞳、各頬3本の線、つながる短い手足を同一比率で維持。基本アトラスは等幅横3セルの通常微笑み／発見の小さい開き口／休憩の閉じ目。追加アトラスは2×2の笑う／聞く／くすぐったい／ありがとう。全身中央配置、透過背景、文字・小物・星・影なし。
元の横3表情方式と2×2方式を維持し、新素材は約265KB。Mocoの共通表示7表情とホームのふれあいを移行。ジャンプの専用旧ポーズ画像への切替をやめ、新造形の基本画像に既存の全身変形を適用。新しい手の独立した振り／左右向きの連続演技ではない。ホームの星は新造形のありがとうの前で表示し、全身と一緒に揺れる。

## Migration boundary
移行済み: Moco共通コンポーネントを使う通常表示、ホームの雲／星／風のふれあい。
未移行: PerformingMocoの独立部品、アニメーション劇場、探索・休憩などの独立部品演技、既存短編v1–v7、創作絵本の専用画像、仲間。既存短編と絵本には旧造形が残る。手の接続が確認された既存部品を、新造形と形の違うまま混在させて動画更新済みとは扱わない。
次: 新造形の前／横／後ろの寸法固定、独立した目・口・全身と接触用の専用素材、固有の分け合う演技、その後短編・絵本を移行。商品画像は想定モックアップで、製造テスト済みではない。親子の好み・識別性・動き・小さいサイズ・刺繍とぬいぐるみ試作で検証する。
