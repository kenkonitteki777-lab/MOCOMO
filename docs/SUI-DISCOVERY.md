# スイと、ひみつさがし

2026-10-08。既存の3雲検索を専用 `SeekGame` へ分離。

## 遊びの構成
- 星の庭で3つの雲を直接押す。雲はSVGによる独自の図形で、全画面幅で64px以上・高さ100px以上のタッチ面。
- 押下→モコモが耳を傾ける→620msで雲がほどける→星／はっぱ／ハートの発見、または静かな風。空の雲を失敗と呼ばず、風の発見として受け止める。
- モコモの発見時は笑顔と小さな弾み、風にはくすぐったい表情。スイは首を傾ける。スイへの挨拶でも返事が返る。
- 見つけたものを「きみの、たからもの」に並べる。得点・期限・ランキング・達成の強制なし。
- 最初の星は中央。以降は3雲からランダムに配置。発見前でも対象の変更は可能。未発見の対象を記憶へ混ぜない。
- 保存完了→「スイのおはなしを読む」→既存6ページ「ほしを、まんなかに」→スイの遊び。架空の物語や読書を実体験として記録しない。

## 整合性と操作
- 揭示中はref/stateの両方で再入力をロック。発見確定でだけ discoveries に追記。
- 手元の発見は遊びの一時状態。明示の記憶ボタンだけで、item／discoveries／companion:sui を既存の保存経路へ渡す。DB・認証・RLSは変更しない。
- 保存refロックと完了画面400msの入力保留で、二重クリックの重複保存／別ボタンへの落下を防止。再遊びでは発見リストをリセット。
- 静かな設定／OSの動き軽減は即時に結果を表示し、移動アニメーションを停止。音の自動再生なし。新音源は追加していない。
- 退出時・タブ非表示時は反応タイマーを解放。途中で中止した揭示を記録しない。
- 了承済みモコモの造形、ホームで追加した表情、スイの既存アトラス、既存の星の庭背景を利用。新たな外部画像やキャラ変更なし。

## 検証
`tests/browser/seek.spec.ts`：空の雲／発見反応、連打ロック、2種類の発見の厳密保存と再読込、遊び↔物語、途中終了、320／390／760／1440pxのタッチ面積・非重複・横はみ出し、quiet／OS動き軽減。
既存のナビ復帰テストは、タップ対象を画面中央へスクロールしてから位置を計測する。自動タップで追加スクロールが起きた場合の誤判定を避け、実際のタップ位置への復帰を検証する。

親子の実使用による夢中度・理解度はまだ未検証。本番のメール認証／クラウド保存の未検証事項を維持。次はトトのキッチンとルナの休憩を個別の触れる体験へ作り込む。

最終検証結果：browser全22件、unit6件、型チェック、production build成功。日本語390px画面で造形・発見物・雲・表情を目視確認。
