# 絵本の表現基準 — 2026-10-07

ユーザー指示: キャラとの出会い、ふれあい、トラブル、仲直り。経験がモコモを成長させる。表情・デザイン・絵・文章の心理描写で表現する。

## 最初のおはなし「ほしを、まんなかに」

モコモとスイの6ページ。出会う→一緒に見つける→二人とも星を持ちたくなる→言葉が出ない→手を差し出す→星を二人で支える。

本文の正は `lib/friendship-story.ts`。各ページは別の場面イラスト。既存のキャラと背景を同じ位置に並べただけの絵ではなく、場面に応じた手、姿勢、眉・目・口、距離、光で気持ちを描く。モコモは白い頭/3つのちょこん、スイは淡い青/1つのしずくの造形を維持。

- 出会い: 手を上げるためらい、控えめな視線。
- ふれあい: 一緒に雲のすきまをのぞく、星へ向かう視線。
- すれ違い: 落ちる星へ伸びた手、驚きとこわばり。
- 心理描写: 「ごめんね」が胸を行き来する。空いた距離、伸ばしかけた手。
- 仲直り: 強い声を出したことを謝る。スイも自分の気持ちを言葉にする。すぐ大きな笑顔や強制の抱擁にはしない。
- 成長: 手を伸ばす前にスイを見る。星を二人で支える。説明や点数でなく次の行動を変える。

善悪のラベルで片方を悪役にせず、星を持ちたい気持ちは二人とも同じ。謝罪を強制しない。安心して読み返せる小さな葛藤。末尾の問いかけは任意、回答の収集・採点なし。

## 体験と保存

BOOKに「モコモのおはなし」と「きみの記憶の絵本」を用意。創作のおはなしを子どもの実際の記憶として保存しない。読了も新しいイベントに変換しない。既存のゲスト/クラウド記憶と絵本保存は維持。ページ切替後は絵へスクロールし、スマホでも絵と心の言葉を読める。

6点の原画は画像制作ツールで制作。アプリは同じ寸法のWebP版を使用。文字はHTMLなので日本語を読みやすく折り返せる。イラストは `public/stories/sui-star/`、プロンプトは `docs/design-reference/sui-star-prompts.md`。個々の場面の最終商用承認、他の仲間の物語、印刷用編集は今後の作業。
