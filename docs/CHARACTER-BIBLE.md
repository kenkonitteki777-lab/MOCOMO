# MOCOMO Character Bible

Moco: いつもそばにいる友達。
Sui: そっと包む。
Ren: 好奇心と冒険。
Toto: 遊ぶことが大好き。
Mogu: 食べるよろこび。
Kira: 夢と想像。
Pon: やさしい気持ち。
Roo: ゆっくり休む。
Muku: 静かに見つめる。
Moyan: もやもやする気持ち。悪役ではない。

Moco visual: 白〜ミルクホワイト、雲そのものが生き物になった輪郭、モコモコ。小さめの黒目、白目の余白、少し離れた目、小さい口、淡いピンクの頬。大きすぎる黒目、怖さ、generic plush/animal化を避ける。

演技: 目を主役に、口は最小限。体は膨らむ/潰れる/傾く。ちょこんは感情メーター。形はシンプル、感情は豊か。
