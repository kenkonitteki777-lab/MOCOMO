# MOCOMO character master · v0.2

Moco: 生きている雲。先生・ヒーローではなく隣にいる友達。

実装中の仮マスター: components/Moco.tsx。240×205 viewBox、ミルクホワイト #fffcf3、淡いピンク #f4c2c1、瞳 #46535c。輪郭は非対称の丸い雲。耳・しっぽ・鼻などの動物記号なし。目は中心から左右35、小さな黒目と周囲の広い余白。口は小さな曲線。

表情: happy / wonder / rest。閉じ目・顔の余白・控えめな口を共有。遊び時に軽いジャンプ、休憩時にゆっくりした呼吸。OSの動き低減と保護者設定を優先する。

このSVGは製品プロトタイプであり、商用最終承認済みキャラクターではない。10キャラクターの名前と役割はCHARACTER-BIBLE.mdを正とする。ともだち一覧の雲マークは仮表示で、各キャラクターの完成デザインではない。
