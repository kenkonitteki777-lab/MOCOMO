## 次の順序と完了条件
1. **ムービーと演技**: 最新のユーザー指示で最優先。24秒の短編を連続演技へ更新。次は横向き・振り返り・仲間の独立した顔と手、接触と受け渡しの演技を制作。正は [FILM-ACTING.md](FILM-ACTING.md)。無音でも感情と行動の理由が伝わること。
2. **キャラと物語**: 出会いから仲直りまでの一本を専用絵で作る。12場面の次作台本は [LUNA-STORY.md](LUNA-STORY.md)。専用絵とアプリ収録は未着手。
3. **看板の遊び**: キッチンを「選ぶ→渡す→キャラごとに反応→分け合う」に。文字を読めない子でも触る場所が分かること。
4. **基盤・音と実機**: 本番認証・家庭別保存・復元、削除と持ち出し、失敗からの復帰を検証。曲と歌の制作、横向き・低速通信を実機で確認。親子の試用から改善する。
