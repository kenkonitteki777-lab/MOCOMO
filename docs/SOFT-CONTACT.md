# 柔らかな全身と、手から手への受け渡し

2026-10-11。GitHub main `20cb367` から着手。了承済みの顔と部品を維持し、短編の体の重さと相手との接触を改善する。

## 演技
- スイが拾った星を持って近づき、モコモも手を伸ばす。14.1〜14.5秒は二人が同じ星を支え、14.5秒からモコモが持つ。スイはゆっくり手を戻す。空中の受け渡し軌道を廃止。
- 肩の支点は体内に固定。伸びる腕は元の手のテクスチャを引き伸ばしてつなぎ、手の先端は独立部品を保つ。新しい横向き専用の腕マスターではない。
- モコモの受け取りに約2.2%、跳ぶ前に最大3.5%の縦の沈み込みを追加。跳ねでは少し伸び、着地で戻る。横は縦の逆数とし、極端な潰れを避ける。歩きも小さい変形。
- 星と二人の手は全身の拡縮・回転・上下動に追従。相手の手の位置をスイの局所座標へ逆変換して腕を解く。顔・体・接触・カメラは共通時計。停止で固定し、動き軽減では場面ごとの静止姿勢。
