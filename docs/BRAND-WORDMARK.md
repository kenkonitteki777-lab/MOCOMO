# モコモのロゴ提案 — 2026-10-07

採用候補としてアプリに試用するA案: カタカナ「モコモ」を主役にする丸い雲文字。深いセージ色、ミルク色の雲、淡いピンクのほっぺ。MOCOMOは小さな補助表記。キャラ本体の了承済みデザインは変えない。

B案はひらがな「もこも」。低年齢の読みやすさはあるが、カタカナより輪郭が複雑で小さなロゴには調整が必要。C案は英字MOCOMO＋小さな日本語。海外展開やグッズ向けの副ロゴ候補であり、子ども向け画面はA案を推奨。

新しいロゴは透明背景の画像生成で制作。public/brand/mocomo-wordmark-v1.webp、720×360、約15KB。全体を保持してサイズと形式のみ最適化。小さいスマホのヘッダーで読めるか確認する。正式な商用マスターとしてのベクター化・単色版・印刷検証は今後。

生成プロンプトの要点: one original horizontal Japanese wordmark, exact モコモ (モ コ モ), rounded readable sage lettering, ivory cloud above first character, two tiny blush dots, supporting exact MOCOMO, genuinely transparent, no mascot/no large eyes/no frame/no extra words.
