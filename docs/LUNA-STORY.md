# 絵本制作案 — モコモとルナの、しずかな雲

2026-10-10。12場面の制作台本。本文と絵の指示を設計した段階で、アプリ収録・専用イラスト制作は未着手。

## 物語の芯
モコモは「友達を元気にするには、楽しく遊べばいい」と思っている。ルナは今日は静かに過ごしたい。好意からのすれ違いを、相手の言葉を聞くことでほどく。モコモが得る経験は「何もしないで隣にいることも、友達へのやさしさ」。子どもへ謝罪や仲直りを強制する説明文を加えない。

## 12場面の台本と絵
| 頁 | 読み聞かせの本文 | 絵・表情・しぐさ |
| --- | --- | --- |
| 1 | 雲のはしが、ももいろにそまるころ。モコモは、小さな月を見つけました。 | 広い夕空。モコモを小さく置き、視線の先の月が入口。気になる目、頭の雲が少し傾く。 |
| 2 | 月の下には、ルナ。「いっしょに、あそぼう！」モコモの声が、ぽんとはずみます。 | 二人が初めて同じ画面に入る。モコモは期待の笑顔、ルナは眠そう。顔と体の向きを違える。 |
| 3 | モコモは、雲をぽんっ。ふわふわのかけらが、雪みたい。「きっと、よろこんでくれる」 | 雲のかけらが弧を描く。モコモの喜びを大きく、ルナの閉じかけの目を小さく対比。 |
| 4 | ところが、ルナの小さな雲まで、ふわり。「あ……」ルナは、そっと押さえました。 | 雲の座布団がずれる小さなトラブル。危険や転落は描かない。ルナの驚き、モコモの笑顔がほどける。 |
| 5 | 「そよかぜなら、どうかな？」モコモは、ふうっ。ルナは、ひとつ、まばたき。 | モコモは相手の反応を探しながら風を送る。短い手を体につないだまま。ルナの頭の形を風の線で隠さない。 |
| 6 | 「いまはね、しずかが、いいな」ルナの声は、雲よりやわらかでした。 | ルナの顔を主役に近景。落ち着いた境界の伝え方。怒り顔にしない。二人の間に余白。 |
| 7 | モコモの手が、とまりました。「あそびたく、なかったのかな」胸の中が、きゅっとします。 | モコモの困った眉と下がる目線。口と手も変える。月を遠くに小さく残し、画面を説明文字で埋めない。 |
| 8 | 「モコモといるのは、すき。今日は、ここにすわりたいの」ルナは、隣の雲を、ぽん。 | ルナが隣を示す。手の支点を保ち、座る場所を絵で分かるように。モコモは相手を見る。 |

| 11 | 何も言わずに、月を見ました。雲が、すこしだけ、ゆれて。「こんな、いっしょも、いいな」 | 再び引きの絵。1頁と同じ空が二人の場所に変わる。視線の先と余白で心理描写を支える。 |
| 12 | モコモは、ルナの隣で、ほっ。明日は、どんな「いっしょ」に、会えるかな。 | 二人と月をシルエットでも識別できる輪郭。静かな幸福。説教や次回へのカウントを置かない。 |

## 制作の合格条件
- 引き／二人の中景／表情の近景を使い分け、同じ背景に表情だけ貼り替えたページにしない。
- ルナ固有の目線・まばたき・頭の形と、モコモの短い手の接続を制作マスターに合わせる。側面・背面が必要な場面は先にマスターを制作する。
- 本文を隠した連続絵で、期待→すれ違い→困惑→気づき→安心が読めるか確認する。
- 創作の出来事をユーザーの記憶に追加しない。実際のREST記憶は休憩として保存する。
- 音楽は任意。無音でも成立させ、風や月に合わせる効果音は音量と停止を確認してから付ける。
- 親子試用で、ルナの希望とモコモの変化が伝わるか確認。人気や寝かしつけ効果を推測で断定しない。

## あそびへの接続
今回の休憩の「となりに座る・風・おやすみ」と共通の世界を使う。ただしゲーム操作で必ずトラブルを起こす仕組みは入れない。絵本で出会ったルナに、子どもが自分で選んだ方法で会いに行けるようにする。専用絵が完成するまでは、仮の絵を商用品質として公開しない。
