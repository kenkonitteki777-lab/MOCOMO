# モコモの音と歌 — v0.2

## 実装したBGM試作「雲のさんぽ」

lib/mocomo-music.tsのオリジナル旋律。60BPM。柔らかい鍵盤風の旋律、ゆっくり立ち上がる和音、まばらな星のベル、低域の静かな風という4層。ステレオの余韻、ローパス、コンプレッサーを通して鋭い音を抑える。サンプル音源を使用しない独自の合成音。ボタンで再生/停止、音量調整。画面を閉じる/別タブに移ると停止。自動再生しない。プロの演奏・録音の最終音源ではなく、没入体験のための器楽スケッチ。

## 演出の方向

出会いは間を空ける、すれ違いは音数を減らす、仲直りは同じ旋律が柔らかく戻る。3〜4ページのトラブル/沈黙では旋律の音数を減らし、星のベルを休め、柔らかい短調の和音にする。5〜6ページの仲直りでは通常の音の重なりに戻る。ページ切替は次の音から反映し、既に鳴る余韻は途切れさせない。読み聞かせの声を優先し、音量の競合を避ける。
