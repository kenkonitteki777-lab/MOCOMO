# モコモの音と歌 — v0.1

## 実装したBGM試作「雲のさんぽ」

lib/mocomo-music.tsのオリジナル旋律。66BPM、柔らかい正弦波の音、ゆるやかな音量変化。ボタンで再生/停止、音量調整。画面を閉じる/別タブに移ると停止。自動再生しない。プロの演奏・録音の最終音源ではなく、没入体験のための器楽スケッチ。

## 演出の方向

出会いは間を空ける、すれ違いは音数を減らす、仲直りは同じ旋律が柔らかく戻る。今の試作は全ページ共通の旋律。場面ごとの編曲は今後の作業。読み聞かせの声を優先し、音量の競合を避ける。
