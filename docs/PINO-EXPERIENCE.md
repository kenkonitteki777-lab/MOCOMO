# ピノの色遊び — 2026-10-08

目標: 色を押す・虹に触るという小さい操作で、キャラとのやり取りを何度でも楽しめる体験。時間制限、点数、正解の色、達成報酬は設けない。子どもの夢中度/育児効果は親子実使用で未検証。

## 実装

- RainbowGameを分離。3つの帯を選び、4色の雲で直接塗る。虹に触ると光がふわっと広がる。ピノへ触ると返事をする。
- ピノの仕草は色への小さなうなずき/音への左右の揺れ。レンの大きなジャンプと異なるテンポ。了承済みのキャラ絵と表情を使用。独立した頭/手の描き分けアニメは未制作。
- 昼/小雨/夕方で背景の光を変える。子が選んだ色は変えない。
- 「音をつける」で初めてAudioContextを生成。選択色に対応する音、遅い旋律、低い和音、控えめな高音の3層。原曲/外部音源なし。録音された楽器・歌・商用マスタリングは未制作。
- 音の停止、保存成功、画面退出、バックグラウンド化、静かな設定で停止。再開は明示操作。OS動き軽減/静かな設定ではCSSアニメを止め、色/表情/返事の操作は残す。
- こんにちは/色変更/虹タッチだけではMEETやCREATEを保存しない。記憶ボタンで1件保存。colors/color/sky/companionを実際の状態から渡す。既存の庭/絵本に同じ色を反映。
- 保存の重複はrefでガード。ダブルクリックの2回目が保存完了後の再遊びボタンに落ちるケースもガード。

## 次の絵本: ふたつのいろ、ひとつのにじ

8場面の制作案。現時点では制作仕様のみで、読める絵本/新しい画像はまだ追加していない。

1. 出会い: ピノが雲の庭で色のしずくを並べている。モコモは自分の好きな色を持って近づく。「その色で、なにができるのかな。」
2. ふれあい: ひとつずつ色を置くと小さい虹が生まれる。二人が同じ高さで驚く。文字を減らし、発見を見せる。
3. すれ違い: ピノは自分の好きな色で虹をいっぱいにしたくなる。モコモのしずくが端へ寄る。ピノはまだ気づかない。
4. 心理: モコモはしずくを手元に戻す。「ぼくの色は、ここにいてもいいのかな。」視線と手の位置で寂しさを描く。怖い/強い叱責は用いない。
5. 伝える: モコモが小さく「この色も、すきなんだ」と伝える。ピノは塗る手を止め、モコモの方を見る。
6. やり直し: ピノが「その色も、ここにしよう」と場所を空ける。好きな色をどちらも残す。片方が我慢して終わる構成にしない。
7. 仲直り: それぞれ持つ虹の端を、雲のまんなかでつなぐ。二人の色が同じ空にある。楽しさを大きい見開きで見せる。
8. 経験による変化: 次の虹を作る前に、モコモが「どの色がすき？」と聞き、ピノも相手の返事を待つ。色遊びへの入口を置く。読み終わりの正解質問/評価はしない。

制作基準: 同じキャラ造形/3D質感、場面ごとの視線とポーズ、絵だけでも分かる因果、1場面1つの感情変化、対立部分は音を薄く、仲直りで色の旋律を戻す。子ども向け本文は「もこも」「ぴの」、ブランド/作品紹介は「モコモ」「ピノ」。全アプリの表記統一は別途見直す。
